05 — VEILLE TECHNOLOGIQUE

Veille —
IA locales

Suivi des évolutions autour des modèles d'intelligence artificielle exécutables directement sur sa machine, sans dépendance à un service cloud.

OUTIL

Ollama

Ollama est un outil qui permet de télécharger et d'exécuter des modèles de langage (LLaMA 3, Mistral, Gemma, Phi…) en local via une simple commande. Il expose une API REST utilisable depuis n'importe quelle application.

Ollama LLaMA 3 Mistral Gemma Phi API REST
INTERFACE

Open WebUI

Open WebUI est une interface web auto-hébergée compatible avec Ollama. Elle offre une expérience similaire à ChatGPT — gestion des conversations, sélection du modèle, plugins — entièrement en local.

Open WebUI Auto-hébergé Docker Ollama
MODÈLES

LLaMA 3, Mistral, Gemma

Ces modèles open source sont les plus utilisés en local. LLaMA 3 (Meta) et Mistral (français) offrent de bonnes performances sur du matériel standard. Gemma (Google) est plus léger et tourne sur des machines modestes.

LLaMA 3 Mistral Gemma Open source Meta
INTERFACE

LM Studio

LM Studio est une application desktop (Windows, Mac, Linux) pour télécharger et faire tourner des LLM en local. Interface graphique complète, pas de ligne de commande nécessaire. Expose aussi une API locale compatible OpenAI.

LM Studio Desktop Windows Mac API OpenAI
CONFIDENTIALITÉ

Données et vie privée

Avec une IA locale, aucune donnée ne quitte la machine. Les prompts, les réponses et les documents traités restent en local, ce qui est essentiel pour des usages professionnels ou des données sensibles soumises au RGPD.
